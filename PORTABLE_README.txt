群众选票格式化打印工具 v0.3.5（Windows 便携版）

1. 请先把整个 ZIP 压缩包完整解压到普通文件夹。
2. 双击 QunzhongVote.exe 运行，程序界面为中文。
3. 不需要安装 Python、Microsoft Office、LibreOffice 或其他运行库。
4. 请勿只复制 EXE；runtime 文件夹是内置文档引擎，必须和 EXE 放在一起。
5. 如果电脑已经安装 Microsoft Word，程序会优先使用 Word 保持原有打印效果；没有 Word 时自动使用内置引擎。
6. 模板、投票数据、预览和导出文件只保存在本机；联网仅用于手动检查 Gitee 更新。

建议环境：Windows 10/11 64 位。
